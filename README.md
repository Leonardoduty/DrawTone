# DrawTone
DrawTone is website which convert your words into abstract square art.

# Try it link
To try the project click: https://draw-tone.vercel.app/

# Quick Start
To quick start just open the link!!

# Features

1. Generative Artwork: converts each word into a unique colored square.

2. Text formatting: provides multiple tools to style your text

3. Undo and redo: Includes inbuilt undo and redo buttons.

4. Ambient chilll music: to chill while making art while writing.

5. Export: you can export your text!

# Run locally

1. Download node.js(node package manager)

2. Clone the repositry

# How it works

The project is based on simple vanilla css, html and js. The main coloumn and row caluclation basically based on ceil sqrt and also word.length. The rest fo the features are also controlled by their codes.
